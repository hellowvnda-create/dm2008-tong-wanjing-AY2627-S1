### The Project

<
We created a Totoro-themed version of the classic Flappy Bird game, inspired by My Neighbour Totoro. Instead of the original bird, players control Totoro as he navigates through obstacles in a whimsical, nature-inspired setting. 
Beyond the basic game mechanics, we customised the visual experience by replacing the original bird and pipes with my own Totoro-inspired illustrations and environmental assets. We also implemented a personalised game-over screen with custom typography, a final score display and a restart button. Something cool we did was to layer the pipes inbetween the bushes. On the coding side, we developed the collision detection, score tracking and restart functionality with spacebar as well so they can keep spamming the game.>

### ✍️ Reflection

<We initially set out to create a Totoro-themed version of the classic Flappy Bird game, where players control Totoro and navigate through obstacles. We wanted to move beyond simply recreating the original game mechanics by giving it a distinct visual identity inspired by "My Neighbour Totoro". Mostly, warm-tone colour palette, and art style similar to glibi studio. Fnding suitable visuals were a challenge and required some editing and collage before being put to use in the code. Something cool we did was to layer the pipes inbetween the bushes.
Pressing the spacebar makes Totoro flap upwards while gravity continuously pulls him downwards. Players earn points by successfully passing through obstacles. If Totoro collides with an obstacle or reaches the boundaries of the screen, the game transitions into a game-over state. Players can then restart using either the spacebar or the restart button.
One of our biggest challenges was implementing the game states and making sure the restart function worked properly. We had to understand how to reset variables such as the score, spawn counter and pipes, while creating a new bird object so that each attempt started fresh. We also had to work through positioning my image assets and ensuring that the collision detection aligned with the customised visuals.
If We had more time, We would explore adding more interactive animations, sound effects and different obstacle designs to make the gameplay more engaging. We would also like to introduce a high-score feature to encourage players to keep improving their scores.>
